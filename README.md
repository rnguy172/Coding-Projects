## Analyzing The Change In Medical Students' Empathy Over Time: UCR STAT 183 Final Project
I collaborated with 3 other class peers to analyze how the empathy of medical students changed over time. Using R and dplyr, I cleaned the large dataset through filtering out unnecessary variables, highly correlated variables, and students who did not participate in 3 or 4 waves of the study. I then created an above average JSE binary outcome variable, and I visualized bar charts and scatterplots for explanatory data analysis. I fitted 5 different mixed-effects logistic regression models and performed statistical model validation on each model to finalize the best fitted model. I then produced and presented a data report, concluding that the school year, gender, relationship status, and physical activity are significant factors.

The RMarkdown script can be found in this repository, and the [Google Slides presentation](https://docs.google.com/presentation/d/1-pPr0Qrm4tZsSC6mA9C7u2nx2qpfMeVqVMBAv6ZkxxQ/edit?usp=sharing) can be found through the link.

## Analyzing Factors Affecting Flight Delays: UCR STAT 167 Final Project
In this project, I collaborated with 5 other class peers to determine variables with a statistically significant impact on a flight being delayed in New York City. Using the nycflights13 package, we manipulated, cleaned, and restructured datasets by scripting explanatory data analysis and data queries with dplyr to filter out cancelled flights, unnecessary variables, and highly correlated variables, and to combine the datasets flights and weather. I was mainly responsible for fitting a multiple linear regression model on the dataset and utilizing stepwise selection based on AIC to analyze the data. Afterwards, I created residual plots, and performed 10-fold cross validation tests to evaluate the models, concluding that weather alone does not explain delays well. Our team created and built a Google Slides presentation report, summarizing and presenting to the class the procedures of the data analysis and the findings of this project. 

The RMarkdown script can be found in this repository, and the [Google Slides presentation](https://docs.google.com/presentation/d/1-7N5y44knKW9p6qgT_iQ9A6-1x7vG9L_ezyr0MT_gR4/edit?usp=sharing) can be found through the link.

## Analyzing Factors In Receiving Timely Breast Cancer Diagnoses: UCR Statistics Department SMART Program Fellow 
With the guidance of a PhD statistics student mentor, I used R to analyze if logistic regression best modeled a dataset of breast cancer diagnoses. I cleaned the large dataset by removing ID, redundant, and highly correlated variables. I then created a histogram of the response variable distribution for explanatory data analysis. Next I fitted a logistic regression model and created coefficient plots. To evaluate the model, I calculated training error rate, training specificity, training sensitivity, and cross-validated error rates. Finally, I developed and presented a data report, summarizing my data analysis process and concluding that the logistic regression model did not model the dataset the best.

The RMarkdown script can be found in this repository, and the [Google Slides presentation](https://drive.google.com/file/d/1ItQpXLAQZwRQmA9vlzUHOpcYUkMU1dFo/view?usp=sharing) can be found through the link.
